# 山久 高山家の記録

川越の糸問屋「山久」高山家の家系と歴史を、家に残っていた紙資料36枚の読み取り記録からまとめた家族向けのページです。

## 構成

| パス | 内容 |
|---|---|
| `index.html` | 記録本体。単一のHTMLファイルで、ブラウザで開くだけで読めます（スマホ・印刷対応） |
| `docs/高山家_古文書読み取り記録_2026-08-31.md` | もとになった読み取り記録（一次記録） |
| `photos/` | 紙資料の写真を入れる場所。`IMG_2872.jpeg` 〜 `IMG_2907.jpeg` を入れると `index.html` の「紙資料36枚の一覧」に表示されます |

## 使い方

- `index.html` をそのまま LINE やメールで送れば、受け取った人はブラウザで開けます（写真は `photos/` を同梱したときだけ表示されます）
- 写真を組み込んだ配布版を作るときは、`photos/` の画像を縮小してから `index.html` に埋め込む作業が必要です

## 注意

読み取り記録は写真からの読み取りで、原本の翻刻ではありません。金額・年号・戒名を対外的に引用するときは、必ず原本にあたってください。
