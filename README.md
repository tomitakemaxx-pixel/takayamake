# 山久 髙山家の記録

川越の糸問屋「山久」髙山家の家系と歴史を、家に残っていた紙資料36枚の読み取り記録からまとめた家族向けのページです。

## 構成

| パス | 内容 |
|---|---|
| `index.html` | 記録本体。単一のHTMLファイルで、ブラウザで開くだけで読めます（スマホ・印刷対応） |
| `docs/髙山家_古文書読み取り記録_2026-08-31.md` | もとになった読み取り記録（一次記録） |
| `photos/` | 紙資料の写真。2026年9月撮影の29枚は `index.html` に埋め込み済み。残りの `IMG_2872.jpeg` 〜 `IMG_2907.jpeg` を入れると「紙資料36枚の一覧」に表示されます |

## 使い方

- `index.html` をそのまま LINE やメールで送れば、受け取った人はブラウザで開けます。埋め込み済みの写真はそのまま表示され、未埋め込みの写真は `photos/` を同梱したときだけ表示されます
- 写真は縮小して `index.html` に埋め込んでいます（現在約9.2MB）。写真が増えたら同じ方法で追加します

## 注意

読み取り記録は写真からの読み取りで、原本の翻刻ではありません。金額・年号・戒名を対外的に引用するときは、必ず原本にあたってください。

## 「髙」と「高」

このページでは家の名を**「髙山」**（はしご高）で統一しています。「髙」は「高」の異体字で、江戸時代の毛筆や石の刻字には書き分けの習慣がありませんでした。現在、髙山家と寺（大蓮寺の過去帳照合表「髙山家（永井家）墓所」、長徳寺の碑「納主 髙山久兵衛」）、および服部安行氏の論考が使っているのは「髙」です。

`docs/高山家_古文書読み取り記録_2026-08-31.md` は2026年8月31日時点の読み取り記録そのものなので、字体を含めて当時のまま残しています。
