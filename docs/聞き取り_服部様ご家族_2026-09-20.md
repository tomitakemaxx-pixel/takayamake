# 服部様ご家族からの聞き取り（電話）

- 日時：令和8年（2026年）9月20日
- 相手：服部民俗資料館（川越市幸町6-8）／服部安行氏のご家族
- 聞き手：髙山浩和
- 形式：電話。録音の自動文字起こしをもとに整理したもので、**聞き手側の発話が中心に残り、相手側は断片的**。以下は要点の再構成であり、逐語ではない。

## 1. 服部安行氏のご逝去

**服部安行氏はすでに亡くなられていた。**「三回忌がちょっと終わったところ」とのこと。没年は確認していない（三回忌から逆算すると令和6年＝2024年ごろか。**要確認**）。

川越市文化財保護協会の会長として、令和3年（2021年）7月31日発行の会報『川越の文化財』第138号に「地先祖参り」を書かれた方。髙山家と永井家の関係を家の外から記した唯一の記録である。

**論考の要所に付された「（と思われる）」の根拠は、氏とともに失われた。**

- 「その家を当初借り受けた（と思われる）のが髙山家であった」の根拠
- 「萬延元（1860）年には行伝寺門前に糸店を移したと思われる」の出典
- 「寛政5（1793）年に糸商を創業した」の出典

## 2. 山新（服部家）の成り立ち

- 服部の家には跡を継ぐ者がいなかったので、**婿を取った**
- その婿が**勤めていたのが大山田**だった
  - 文字起こしでは婿の身分が「教員」と聞こえるが、直後に「勤めていたのが大山田」とあるため、**奉公人の類の聞き違いとみられる（要確認）**
- 「大山田に勤めていた人をお婿さんにして、**二人でこの山田屋の屋号も一緒にいただいた**ことになるのかしらね。それでお店を始めたらしいです」
- 当初は**履物・薬・傘**を扱った
- 始まりは**明治に入ったころ**

### 意味

髙山家の伝承（大山田の丁稚から番頭になり、暖簾分けで糸屋になった）と**同じ構造**。しかも**家の外から出てきた話**である点に価値がある。「大山田に勤めた者に屋号を分けて店を出させる」のが本家のやり方だったことになる。

ただし時期は異なる。**山新は明治ごろ、山久は寛政5年（1793年）。**四軒の分かれた時期は同じではない。

## 3. 服部民俗資料館の展示

「うちで使ってたもの。代々ここ、この山新で生活して使ってたものとか、家族が旅に出て持っていったものとか、日常で使っていた古いもの」。**髙山家に関する資料があるという話は出ていない。**

## 4. 服部氏が語っていたこと（髙山家について）

- 「山久さんは、そのお店を……どう理解したのかわかんないんですけど、**そのうちの方のお墓も丁寧に、ずっとお参りとかしてた**っていう話はしてましたね」
- 「**それを、そのお墓をあちらの方に移した**とかいう話も言ってました」
  - 平成30年（2018年）の長徳寺への移転を指すとみられる。**論考はその3年後に書かれている**
- 「**前の人のこともちゃんとお参りしてたら、こうだよ**みたいな話をしてました」（**要確認**）
